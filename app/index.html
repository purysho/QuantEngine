    Available datasets

    CSV format

    UTF-8 wide format: date,A,B,.... Dates must be unique, strictly increasing and use YYYY-MM-DD. Every price must be positive and finite; missing values are rejected. Include at least 40 observations, up to 64 assets and a file smaller than 32 MB.

    date,Asset A,Asset B
2026-01-02,100.00,80.00
2026-01-05,101.20,79.60
...

    Use consistent trading-day spacing and adjusted prices where appropriate. The engine does not infer dividends, splits, currencies or missing data.

    Assistant & voice

    OFFLINE

    Open the assistant with Ctrl+K. For voice, install Handy (free, offline speech-to-text: winget install cjpais.Handy), choose its CPU-friendly Parakeet model, then hold its shortcut and speak into the Ask box. Every request is logged to assistant-log.jsonl in the storage folder.

    For free-form questions only, e.g. llama.cpp, Ollama or LM Studio running on this computer. Only localhost addresses are accepted. The model answers from a summary of your latest report and can never change settings or run work.

    Resource & background controls

    Closing the window keeps Quant Engine in the system tray. Choose Quit Quant Engine from the tray menu to stop it. Calculations run while the computer is awake.
