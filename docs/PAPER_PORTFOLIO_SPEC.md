# Capital-aware forward paper portfolios

Approved objective: higher net compounded dollars than a matched investable Nasdaq-100 holding, tested at100/10,000/1,000,000 USD. Existing historical failures remain development evidence.

First release: local SQLite paper campaign, desktop dashboard and a JSON quote-ingestion interface. No broker orders, credentials, automatic provider subscription or real-money adapter. Data feed installation and independent custody remain external prerequisites; absence must be visible. Cross-sectional research is the subsequent project, gated by permitted point-in-time membership/corporate-action data; it is not fabricated with current constituents.

Each campaign freezes symbol (initially QQQ as an instrument placeholder pending feed/account verification), source label, recorded/prospective mode, initial capital scales, execution assumptions, exact engine source hash, Python version and strategy definitions. Three books per scale: buyhold, vol15_interval1, vol15_interval5. Challenger warmup requires21 observed session quotes; it stays cash meanwhile, and this is visible in comparative returns. Targets use trailing20 split/dividend-adjusted log returns,15% cap,10pp band and specified minimum interval. Orders committed after processing a quote can execute only on a later session quote, after their durable local commit. No same-event fills. No alpha-based selection or automatic promotion.

Daily quote contract: unique event_id, symbol, session ISO date, previous_session ISO date or null, UTC asof, bid/ask, bid_size/ask_size, split_ratio(default1), dividend_per_share(default0). Timestamps are aware; future quotes rejected. Prospective quotes must be current within300s of local receipt and newer than campaign creation and prior decision commit. Session linkage detects missing observations; a gap halts fills, clears pending targets and permanently marks evidence incomplete. Pause/halt accepts marks without trading; resumption never silently certifies earlier gaps. Imported recorded observations never become genuinely unseen evidence. Local receipt time and hash chain do not establish independent custody.

SQLite transactions atomically journal input, fill/order results, target commitments and resulting state. Duplicate IDs, out-of-order sessions, clock regression, crossed quotes and invalid numeric inputs fail closed. Resume/reopen verifies event/state hash chain and engine hash. Local owner can rewrite all files; reports disclose that trust boundary. Input size/campaign count/row count bounded. Export excludes filesystem paths and secrets.

Execution: long/cash, one ETF, no leverage. Decimal cash/shares; frozen share step(default0.000001), minimum notional(default1 USD), fee_bps(default10), fixed_fee(default0), maximum participation in quoted side size(default10%), modeled adverse impact_bps(default10 times sqrt(qty/side_size)). Buy affordability solved with all charges; sells cannot exceed holdings. Residual IOC quantities expire visibly and are reconsidered only by a subsequent committed target. Side-size limits are conservative snapshot assumptions, not measured daily capacity. Each portfolio is an independent counterfactual, not nine simultaneous claims on one quote. Dividends credit prior holdings; splits adjust shares before marks/fills and preserve total-return features. Cash interest defaults zero and is disclosed. Personal tax and data/runtime costs excluded and explicit; no after-tax performance claim.

Dashboard: campaign/mode/source, no-feed/awaiting-data, quote age, incomplete evidence, pause/resume, model freeze, scales, equity/cash/shares/net returns/drawdown/excess dollars, recent fills/rejections and orders. Export full local journal and summary. No statistically supported capital range claimed from simulator assumptions.

Acceptance: exact cash/fee reconciliation, independent scale effects, min-order/rounding, no overspend, partial fills, source timestamps and decision-before-outcome, duplicate/reorder/gap/restart/tampering failures, dividends/splits, safe UI text, shared worker pause/shutdown, persisted reopen/export. Synthetic fixtures prove software only; prospective market performance remains untested until a real feed produces eligible observations.
